# Entombed Sentinels package

This is the sole architecture-reference encounter for `EncounterPackageV1`.
It contains validated shared facts, the `ptr_2026-08-13` timing profile, tactic
declarations, an abstract Learn 2D arena, an independent Train 3D world arena,
and package-owned lazy runtime loaders.

Only `sentinels_helical_toxins` is ready. Learn 2D trains the exact four-green
composition rule through a movable top-down character, attached toxin icons,
and abstract meeting sectors without importing world geometry. Train 3D uses a
headless fixed-step mechanic module for movement, contact, third-player failure,
and the 28-second window. The reusable platform renderer consumes its immutable
actor/aura/effect snapshots and provides the third-person camera. The full-fight
and Mythic scenarios intentionally remain planned.

Movement bindings and HUD visibility/scale are supplied by the shell through
the package runtime contract. The encounter does not read global or legacy
L'ura storage keys. Raid-plan imagery and editable roster detail remain open
until reviewed evidence arrives through the project inbox.

All timings remain PTR-labelled. No live profile exists yet.
