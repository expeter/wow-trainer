# Entombed Sentinels package

This is the sole architecture-reference encounter for `EncounterPackageV1`.
It currently contains validated shared facts, the `ptr_2026-08-13` timing
profile, tactic declarations, an abstract Learn 2D arena, an independent Train
3D world arena, and planned focused/full-fight scenario metadata.

No scenario is playable in Stage 4A. `status: planned` is intentional. The
first runtime slice will implement the Helical Toxins Learn 2D tutorial without
importing the Train 3D arena. Exact movement, collision, bots, and fixed-step
simulation follow in the Train 3D slice.

All timings remain PTR-labelled. No live profile exists yet.
