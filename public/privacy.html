Privacy

The trainer works without an account. It does not submit gameplay, profile, or ranking data automatically. Guild playtesters can explicitly send a feedback report.

Services used

GitHub Pages hosts the static files. There are no advertising, analytics, fingerprinting, login, leaderboard, or unrelated tracking services in this release.

Preferences such as key bindings, HUD layout, audio channels, and local tactics are stored only in your browser. Clearing site data removes them.

Guild feedback

The optional “Report bug” form sends the text and screenshots you choose, plus the current trainer version, page, encounter, mode, difficulty, browser user agent, and viewport size. Screenshots are stored as supplied and may contain names or other visible information, so review them before sending.

Reports are kept in private server storage for maintainer triage. They are not published to GitHub automatically and have no public read link. The shared guild access code is remembered only for the current browser tab after a successful report.

Source and contact

The trainer source is published in the GitHub repository. Guild playtest reports should use the private form; repository issues are public.
